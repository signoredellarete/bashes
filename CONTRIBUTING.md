# Contributing to Bashes

Thank you for taking the time to improve Bashes.

## Issues Are Welcome

Bug reports and feature requests are the best way to contribute. Before opening an issue, please check the existing issues and include enough detail to reproduce or evaluate the request.

- Use the bug report form for reproducible problems.
- Use the feature request form for proposed behavior or workflow improvements.
- Do not include passwords, private keys, internal hostnames or other sensitive data.

## Pull Requests

Bashes is currently maintained by a single author and does not accept external pull requests. This keeps implementation and release ownership manageable while the project evolves quickly.

Please open an issue instead. Clear reports, test cases and focused design feedback are valuable and can be incorporated by the maintainer without requiring you to prepare a pull request.

Security issues must be reported privately as described in [SECURITY.md](SECURITY.md).
